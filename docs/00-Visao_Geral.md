# Sistema FO — Visão Geral

O Sistema FO é uma aplicação web para registro, homologação, publicação e acompanhamento de Fatos Observados de militares da Organização Militar.

## Objetivos

- Centralizar o lançamento de Fatos Observados.
- Controlar homologação antes da publicação.
- Permitir consulta de histórico por militar.
- Gerar informações para boletim.
- Controlar ranking e saldo de FO.
- Registrar dispensas de militares por oficiais.

## Regra de pontuação

A partir da versão 1.5.0, o sistema trabalha com saldo simples:

- FO positivo: +1.
- FO negativo: -1.

O campo de pontos não é exibido no lançamento nem nas consultas, pois todos os fatos possuem o mesmo peso.
