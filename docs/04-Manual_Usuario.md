# Manual do Usuário

## Acesso

O usuário acessa o sistema com login e senha definidos pela administração. Em cadastros automáticos, o login e a senha inicial usam a identidade militar.

## Meu Histórico

A tela Meu Histórico apresenta os Fatos Observados publicados para o militar vinculado ao usuário.

O saldo é calculado da seguinte forma:

- FO positivo soma +1.
- FO negativo soma -1.

## Primeiro acesso

No primeiro acesso, o usuário deverá obrigatoriamente:

1. informar a identidade militar;
2. criar uma nova senha com pelo menos 6 caracteres;
3. aceitar os Termos de Uso do Sistema FO.

Sem a troca de senha e o aceite dos termos, o acesso às demais telas do sistema será bloqueado automaticamente.
